# Tasks (prompts are given verbatim)

T1. "A teacher has just marked a unit test for a class of 28 students.
Build the screen they use to review how the class did and decide what
to do next."
Task-fit checklist: (a) students needing support are identifiable
without scanning every row; (b) results carry a basis (previous test,
class average or target); (c) the teacher can open one student in
context without losing the class view.

T2. "A portfolio manager opens their book in the morning. Build the
screen they use to see what moved since yesterday and understand why."
Task-fit checklist: (a) the largest moves are surfaced first; (b)
changes carry their basis (yesterday's close, benchmark); (c) the cause
or evidence for a move is reachable from the move itself.

T3. "A payments operations analyst has a list of failed payouts to work
through. Build the screen they use to resolve them."
Task-fit checklist: (a) one failure can be worked on with its evidence
visible; (b) the analyst can act (retry, escalate) with the consequence
stated; (c) progress through the list is visible.
