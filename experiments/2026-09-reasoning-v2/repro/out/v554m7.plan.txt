The screen is a dashboard for the head of school to present the current state of the school to the board. It includes key metrics such as enrollment numbers, student performance, and financial health. The layout consists of a header with the school's name and a title indicating the term's performance summary. Below the header, the dashboard is divided into two main sections: a left column for key metrics and trends, and a right column for detailed charts and tables. The left column features a card with important metrics and a trend line, while the right column contains a larger chart and a data table, providing a comprehensive view of the school's performance.
