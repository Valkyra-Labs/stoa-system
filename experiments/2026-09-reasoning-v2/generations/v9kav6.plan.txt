This screen serves as a preparation dashboard for a teacher to gather evidence and structure their upcoming parent meeting. It is organized into three primary sections: a sidebar for quick reference to the student's profile and history; a main view containing a summary card with key metrics (attendance, behavior, grades); and a detailed data table below for specific incidents or achievements.

The layout features a header with the student's name and a "Meeting Notes" button. Below, a prominent "Student Overview" card displays high-level status using `Metric` and `Status` components. Adjacent to this is a `Timeline` showing recent behavioral or academic events. The lower section uses a `DataTable` to list specific interactions with the parent, allowing the teacher to filter by type (e.g., "Positive," "Concern"). A `ReviewQueue` pattern is implemented at the bottom, letting the teacher prioritize which points to discuss first, effectively guiding the conversation flow before the meeting begins.
