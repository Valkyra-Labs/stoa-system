This screen is a comparison tool for a financial adviser to select the best fund for a client. It visually pits two funds side-by-side across key financial metrics like expense ratio, historical returns, and risk profile.

The layout features a header with the client's name and a "Recommend" button. Below, two large cards display each fund's summary with a primary metric (e.g., 5-year return) and a secondary delta (change vs. benchmark). A central "Comparison" component automatically aligns these cards, showing identical metrics for easy visual contrast. Beneath the cards, a detailed "DataTable" allows the adviser to drill into specific data points, filter by performance criteria, and sort by preference. Finally, an "AuditLog" footer tracks every recommendation made for compliance. The design emphasizes clear, immediate differences to support a confident, data-driven decision.
