The screen serves as a static report to showcase the school's performance for the board. It is divided into three main sections: an overview of key metrics, a chart displaying trends, and a detailed comparison table. The layout features a header with the school's name and the term summary. A sidebar provides navigation to different sections of the report. The main content area includes a card for each section, ensuring the information is clear and easy to digest. This setup allows the head of school to confidently present the school's achievements and status without any need for interaction.
