The screen serves as a dashboard for a head of school to present the current state of the school to the board. It is designed to be static and informative, showcasing key performance metrics and recent trends without any interactive elements. The layout consists of a header with the school’s name and a subtitle indicating the current term. Below the header, the dashboard is divided into two main sections: a left sidebar for navigation to different categories of information and a main content area. The main content area features a series of cards, each displaying a specific metric or chart, such as enrollment numbers, financial summaries, and academic performance trends.
