The main goal of this screen is to provide a clear, prioritized overview of portfolio performance changes since the previous day, enabling the manager to quickly identify significant movements and understand their drivers without sifting through noise.

The layout supports this by placing the most critical information—aggregate performance deltas and top movers—at the very top. A dashboard-style header displays high-level metrics (e.g., total P&L, sector exposure changes) using large, clear numbers. Below this, a focused list or table highlights assets with material changes, grouping them by reason (e.g., "Market Impact," "Fundamental News," "Rebalancing"). This allows the manager to scan for outliers immediately.

A secondary column or modal offers context for each movement, explaining *why* it happened with links to news or trade logs, preventing information overload on the main screen. Navigation controls let the user drill down into specific sectors or assets, ensuring the view remains consistent while allowing deep dives only when necessary. This hierarchy respects the user's need for speed in the morning while providing the detail required for decision-making.
