The screen is designed to help a financial adviser compare two investment funds and recommend one to a client. It features a side-by-side comparison of the funds' key metrics, such as performance, risk, and fees, along with visual aids like charts and trend lines. The layout consists of a header with the comparison title, a sidebar for navigation, and a main area divided into two columns, each representing one fund. Each column contains a summary card with essential metrics, a performance chart, and a risk profile. Below the charts, there is a table comparing specific financial data points. The adviser can toggle between different types of charts and data views to make an informed decision.
