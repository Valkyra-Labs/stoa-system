This screen is an **Inspector** pattern designed for a payments analyst to resolve individual failed payouts. The layout features a **Header** showing the payout's ID, status, and a "Resolve" action button. Below is a **Card** containing the primary payout details (amount, recipient, reason for failure) alongside a **Context** section displaying related transaction history and API error logs.

The core of the screen is a **DataTable** listing all failed payouts, with a **FilterBar** for searching by error code or date, and **BulkActions** for selecting multiple items. Upon clicking a row, the **Drawer** component slides in to show the detailed **Inspector** view for that specific payout, allowing the analyst to read the full error context and submit a resolution decision (e.g., "Retry," "Escalate," or "Void"). This ensures the analyst stays in context while efficiently navigating through the queue.
