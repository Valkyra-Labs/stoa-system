This screen serves as the definitive Term Report for the school board, presenting a static, high-level overview of the school's performance to be presented verbatim next week. The layout features a clean header with the Term title and a "Print/PDF" action. Below, a primary dashboard section displays key metrics (e.g., Enrollment, Test Scores, Budget) using `Metric` and `Delta` components to highlight growth or decline. Two visual charts (`Chart`) sit beneath the metrics to illustrate enrollment trends and budget allocation. A secondary column contains an `AuditLog` showing recent compliance updates and a `Status` indicator for accreditation. The bottom section is a concise `DataTable` summarizing departmental highlights. The entire design prioritizes clarity and readability, using neutral tones and clear typography to ensure the data is instantly understandable by non-technical stakeholders.
