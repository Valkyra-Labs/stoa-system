The screen is a static report for the school board, displaying key performance indicators (KPIs) and trends for the current term without any interactive elements. It is divided into three main sections: an overview of the school's performance with key metrics, a visual comparison of recent trends, and a detailed timeline of significant events. The layout includes a header with the school's name and the term period, a sidebar with navigation links, and a main content area with cards and charts to present data clearly and concisely.
